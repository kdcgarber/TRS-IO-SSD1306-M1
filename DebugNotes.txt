# Debug notes:

Here are my notes to setup my PC to view output from the ESP-WROOM-32 usb port.
To get it to work, I did this:

To add the CP210x driver for your OS to have the USB port be used as a serial device.
The download location I used was this: https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads
I chose this one: CP210x Windows Drivers with Serial Enumerator

After it is installed, I then use Putty to view the serial port (com4 for one of my TRS-IO boards)
On my windows machines I use MobaXterm instead and in linux I do use just plane Putty, (Moba is a multi-window version of Putty, but Putty works quite well. https://mobaxterm.mobatek.net/download.html)

When that is complete, I just plug a usb cable into the pc and my TRS-IO ESP-WROOM-32 port which will power up the board.  Then with Putty open, I can connect the serial port to the new USB port and set the speed to 115200.  It should show the boot log as  the boot progresses.


I added additional print statement in my build so I can see the memory growth as the code runs to narrow down what is consuming the memory and causing the code to repeatedly crash and restart.
